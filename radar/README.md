# 雷达图查询

按地区查询中央气象台最新雷达图，并通过 OneBot 发送到群。

## 安装与运行

需要 Windows、Python 3.11 或更高版本，以及已配置好的 NapCat / OneBot v11 服务。模块可独立运行，不需要人格插件、人格文件或历史数据库。依赖版本来自本机现有环境，Python 3.12.9；公开副本尚未重新联网安装或接入真实 QQ 测试。

1. 先配置 NapCat 的 HTTP 接口和正向 WebSocket 接口。
2. 运行 `setup_radar.bat`。脚本在本目录创建 `.venv`、安装 `requirements.txt`；仅在本地配置不存在时，将 `radar.example.json` 复制为 `radar.json`。
3. 编辑 `radar.json`，设置接口地址和需要启用的功能。
4. 运行 `radar.bat`。关闭前台进程即可停止这个模块。

安装脚本不会覆盖已有本地配置。仓库只提供 `.example.json` 模板，实际配置、虚拟环境和日志均被忽略。修改运行配置后重启模块以确保全部设置生效。

## 配置

- `groups`：允许响应的群号数组，默认 `[]`，因此不会向任何群回复。确认目标群后自行填写，例如 `[123456789]`（仅为占位示例）。
- `who`：可选昵称前缀，示例为 `小Q`。
- `regions`：地区名到中央气象台页面 URL 的映射，示例保留全国及七大区。
- `ws_url` / `napcat_http`：OneBot 接收事件与发送消息的地址，默认使用本机端口 3002 / 3001。
- `ack_phrases` / `fail_phrases`：确认与失败时随机选用的文本。

示例指令：`查询全国雷达图`、`小Q 查询华东降水雷达图`。程序从页面提取 `imgpath` 图片地址，若未找到则尝试匹配产品 PNG 地址。

## 数据与使用边界

数据页面来自 [中央气象台](http://www.nmc.cn/publish/radar/chinaall.html)。本仓库不包含雷达图片，图片与数据的权利不因代码许可证而改变。此模块的 HTTP / WebSocket 请求未实现访问令牌配置；如你的 OneBot 接口要求鉴权，需要自行补充对应接入逻辑。不要直接把本机免鉴权接口开放到公网。
