# 定时消息

按时间规则读取本地文本文件，通过 OneBot 发送到指定群。

## 安装与运行

需要 Windows、Python 3.11 或更高版本，以及已配置好的 NapCat / OneBot v11 服务。模块可独立运行，不需要人格插件、人格文件或历史数据库。依赖版本来自本机现有环境，Python 3.12.9；公开副本尚未重新联网安装或接入真实 QQ 测试。

1. 先配置 NapCat 的 HTTP 接口和正向 WebSocket 接口。
2. 运行 `setup_scheduler.bat`。脚本在本目录创建 `.venv`、安装 `requirements.txt`；仅在本地配置不存在时，将 `schedule.example.json` 复制为 `schedule.json`。
3. 编辑 `schedule.json`，设置接口地址和需要启用的功能。
4. 运行 `scheduler.bat`。关闭前台进程即可停止这个模块。

安装脚本不会覆盖已有本地配置。仓库只提供 `.example.json` 模板，实际配置、虚拟环境和日志均被忽略。修改运行配置后重启模块以确保全部设置生效。

## 配置

模板中的唯一示例任务 `enabled` 为 `false`，不会自动发消息。群号 `123456789` 仅为占位；应先填写自己的目标群、正文和时间，再启用任务。

- `napcat_url`：OneBot HTTP 接口地址。
- `token`：可选访问令牌，模板为空。真实值只填写在被忽略的 `schedule.json` 中。
- `schedule[].name`：每个任务使用不同名称。
- `enabled`：任务开关。
- `at` 与 `days`：如 `21:00` 与 `每天`、`工作日`、`周末`、`周一,周三`。
- `cron`：也可直接指定标准五段 cron；同时设置时优先采用 `cron`。
- `type`：目前为 `text`。
- `file`：相对本模块目录的 UTF-8 文本路径，例如 `msg/night.txt`。
- `group_id`：目标群号。发送前会检查机器人是否在该群。

时间按运行电脑的本地时区解释。三个 `msg/*.txt` 均为重新编写的通用示例，当前配置只引用 `night.txt`。更改消息内容时注意不要把私人信息提交到仓库。

配置大约每 30 秒检查一次，但主循环接近按分钟运行，实际生效时间取决于循环。为明确生效，修改后可重启模块。
