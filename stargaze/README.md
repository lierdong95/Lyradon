# 观星条件查询

通过地理编码查找地点，结合天文天气与简化月相估算，输出观星适宜指数。

## 安装与运行

需要 Windows、Python 3.11 或更高版本，以及已配置好的 NapCat / OneBot v11 服务。模块可独立运行，不需要人格插件、人格文件或历史数据库。依赖版本来自本机现有环境，Python 3.12.9；公开副本尚未重新联网安装或接入真实 QQ 测试。

1. 先配置 NapCat 的 HTTP 接口和正向 WebSocket 接口。
2. 运行 `setup_stargaze.bat`。脚本在本目录创建 `.venv`、安装 `requirements.txt`；仅在本地配置不存在时，将 `stargaze.example.json` 复制为 `stargaze.json`。
3. 编辑 `stargaze.json`，设置接口地址和需要启用的功能。
4. 运行 `stargaze.bat`。关闭前台进程即可停止这个模块。

安装脚本不会覆盖已有本地配置。仓库只提供 `.example.json` 模板，实际配置、虚拟环境和日志均被忽略。修改运行配置后重启模块以确保全部设置生效。

## 配置

- `groups`：允许响应的群号数组，默认 `[]`。确认目标群后自行填写，例如 `[123456789]`（占位示例）。
- `who`：可选昵称前缀，示例为 `小Q`。
- `ws_url` / `napcat_http`：OneBot 接口地址。
- `ack_phrases` / `fail_phrases`：通用确认与失败文案。
- `places`：可选地点别名表。条目值可包含 `lat`、`lon`、`label`，以下划线开头的说明项会被跳过。模板未包含私人地点。

示例指令：`观星 云南丽江`、`小Q 观星 大理市`。观星时间按中国标准时间附近的夜间预报选取。

## 数据与算法

地点查询使用 [Open-Meteo 地理编码](https://geocoding-api.open-meteo.com/v1/search)，天文天气使用 [7Timer](http://www.7timer.info/)。指数按云量、透明度、视宁度加权，并依据降水与月光调整。月相使用平均朔望周期近似估算；该指数是原项目保留的经验算法，不是天文台认证的预测指标。

第三方数据与服务按各自条款提供，代码许可证不包含对这些数据的重新授权。接口请求未实现 OneBot 访问令牌配置；要求鉴权的部署需自行补充接入逻辑。
