# 关键词回复

按配置中的触发词选择文本回复；同一触发词有多个候选时，尽量避免连续重复同一条回复。

## 安装与运行

需要 Windows、Python 3.11 或更高版本，以及已配置好的 NapCat / OneBot v11 服务。模块可独立运行，不需要人格插件、人格文件或历史数据库。依赖版本来自本机现有环境，Python 3.12.9；公开副本尚未重新联网安装或接入真实 QQ 测试。

1. 先配置 NapCat 的 HTTP 接口和正向 WebSocket 接口。
2. 运行 `setup_wordlib.bat`。脚本在本目录创建 `.venv`、安装 `requirements.txt`；仅在本地配置不存在时，将 `wordlib.example.json` 复制为 `wordlib.json`。
3. 编辑 `wordlib.json`，设置接口地址和需要启用的功能。
4. 运行 `wordlib.bat`。关闭前台进程即可停止这个模块。

安装脚本不会覆盖已有本地配置。仓库只提供 `.example.json` 模板，实际配置、虚拟环境和日志均被忽略。修改运行配置后重启模块以确保全部设置生效。

## 配置

- `groups`：允许响应的群号数组，默认 `[]`。确认目标群后自行填写，例如 `[123456789]`（占位示例）。
- `ws_url` / `napcat_http`：OneBot 接口地址；公开副本把原代码中的固定地址改为可配置，默认仍为本机 3002 / 3001。
- `llm_prefixes`：遇到这些开头的消息就跳过；示例为 `小Q`，可设为 `[]`。这是避免与其他对话服务争抢消息的规则，不依赖 LLM 或人格插件。
- `rules`：触发词到非空回复数组的映射，模板内容全部为通用示例。

例如普通群消息 `早上好` 可以匹配词库；以 `小Q` 开头或包含对机器人 @ 的消息会跳过。匹配采用子串规则，多个词条同时命中时采用配置中先出现的一项。

本模块会记录部分触发消息到本地日志，因此日志不纳入仓库。接口请求未实现 OneBot 访问令牌配置；要求鉴权的部署需自行补充接入逻辑。
